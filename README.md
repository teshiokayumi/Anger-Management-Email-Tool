# 🛡️ 教員向け アンガーマネジメントメールツール

保護者対応に困っている先生のためのツールです。感情のままに書いたメモや本音を、AIが冷静でていねいな文面に書き直し、Gmailの下書きに保存します。
さらに、たまった下書きを**エージェントが読み解いて課題を見つけ、可視化し、対応策を考え、学年主任との打ち合わせ資料**にまとめます。

## ✨ 主な機能

### ✉️ メールを書く（アンガーマネジメント）
- **AIによる文面の推敲**: 感情のままに書いたメモを、保護者との信頼関係を損なわない言葉遣い（クッション言葉など）に書き直します。
- **メンタルケア**: メモから「怒り・ストレス度」を判定し、先生への労いのアドバイスを表示します。
- **Gmailの下書きに保存**: 作成した文面をワンクリックでGmailの下書きに保存します。
- **分析用の記録**: 本音メモとストレス度を、このPC内（`data/case_log.jsonl`）にだけ記録します。保護者に送るメールには含まれません。

### 🧭 課題を見つけて相談資料をつくる（課題分析エージェント）
エージェントが次の手順を自動で進めます。

1. **収集**: Gmailの下書きと、ツールの記録（本音メモ・ストレス度）を突き合わせる
2. **読解**: 1件ずつ読み、保護者対応かどうかを判定。分類・緊急度・未解決の論点を整理し、氏名は「保護者A」のように匿名化
3. **集計**: 分類ごとの件数、ストレス度、夜間（19時以降・7時前）の対応、同じ保護者とのやりとり回数
4. **課題抽出**: 複数の案件に共通する「背景にある課題」を、根拠となる案件つきで見つける
5. **アプローチ立案**: 課題ごとに「誰が・いつまでに・何をするか」と、学年主任に相談したいことをまとめる

結果は画面上で確認・編集でき（アプローチ案の表、相談したいこと、要約）、**Word資料（.docx）**または Markdown でダウンロードできます。
Gmailに接続しなくても「サンプルデータ（デモ用）」で流れを試せます。

## 🛠 使用技術

- **言語**: Python 3
- **フロントエンド**: [Streamlit](https://streamlit.io/)
- **AI/LLM**: Google Gemini API（`google-genai` / Interactions API、既定モデル `gemini-3.7-flash`）
- **メール連携**: Gmail API (Google OAuth 2.0)
- **可視化・資料**: matplotlib / python-docx

## 🚀 起動方法

```bash
pip install -r requirements.txt
```

Gemini APIキーを環境変数に設定します（画面左の「設定」に入力しても使えます）。

```bash
set GEMINI_API_KEY=あなたのAPIキー
```

```bash
streamlit run app.py
```

Gmail連携には、Google Cloud Console で作成した `credentials.json`（デスクトップ アプリ）をこのフォルダに置き、画面左の「Gmail連携」からログインしてください。

## ☁️ Cloud Run へのデプロイ

手順は [DEPLOY.md](DEPLOY.md) にまとめています。Cloud Run 版では、画面の「Googleでログイン」から各自のGmailに接続します（`GOOGLE_OAUTH_CLIENT_JSON` と `OAUTH_REDIRECT_URI` を設定）。APIキーとOAuthクライアントは Secret Manager に置き、コードには書きません。

## 🔒 個人情報の扱い

- Gemini API は `store=False`（会話をサーバーに保存しない設定）で呼び出しています。
- Gmailの権限は「下書きの作成・読み取り」（`gmail.compose`）だけを要求します。受信トレイは読みません。
- Cloud Run 版では、本音メモの記録はブラウザのセッション内だけに保持し、サーバーには残しません。
- 本音メモの記録（`data/`）、`token.json`、`credentials.json` は `.gitignore` 済みで、リポジトリには含まれません。
- 打ち合わせ資料には氏名を載せず、「保護者A」「生徒」などに置き換えています。内容は校内限りで扱ってください。
