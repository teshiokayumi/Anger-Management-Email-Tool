# 🛡️ 教員向け アンガーマネジメントメールツール

教員が直面する保護者対応などのストレスフルな場面において、感情的なメモや本音をAIが冷静でプロフェッショナルな文面に推敲し、そのままGmailの下書きに保存できるサポートツールです。

## ✨ 主な機能

- **AIによる文面推敲**: 感情のままに書いたメモを、保護者との信頼関係を損なわない適切な言葉遣い（クッション言葉など）に自動変換します。
- **メンタルケア機能**: 入力されたテキストから「怒り・ストレス度（スコア）」を分析し、教員への労いのアドバイスを表示します。
- **Gmail下書き連携**: AIが作成したメール文面を、ワンクリックで自身のGmailアカウントの「下書き」に直接保存します。
- **リラックスできるUI**: 背景画像を設定し、心理的負担を和らげる温かみのあるデザインを採用しています。

## 🛠 使用技術

- **言語**: Python 3
- **フロントエンド**: [Streamlit](https://streamlit.io/)
- **AI/LLM**: Google Gemini API (`gemini-3.6-flash`)
- **メール連携**: Gmail API (Google OAuth 2.0)
